# Статус стенда с импортированными данными

В интеграционной ветке этот сценарий не используется и не проверен.
Разрешён только синтетический стенд из [DEPLOY.md](DEPLOY.md).

Локальные списки компаний и VITE_DEMO_ACCOUNTS не являются серверными правами.
Для любого будущего стенда с импортированными данными отдельно потребуются
миграция авторизации, индивидуальные аккаунты, memberships и news grants,
проверка ACL и отдельное согласование использования данных.
Нельзя назначать доступ по данным persons или связям F–U.

В рамках интеграции реальные CSV, PostgreSQL-профили и документы не загружались.
Внешний анализ DB-контекста запрещён; обходить guard через frontend нельзя.
