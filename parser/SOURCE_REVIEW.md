# Проверка кандидата HTTP RSS — 23.10.2026

Кандидат: пресс-релизы Банка России, технический source_name `cbr-press`.

- Официальный каталог: https://www.cbr.ru/development/RSS/ — публикует RSS 2.0 `http://www.cbr.ru/rss/RssPress`.
- HTTPS-кандидат: https://www.cbr.ru/rss/RssPress — инструмент исследования распознал application/rss+xml, но не отобразил XML. Полноценный приём реальной ленты коллектором не выполнялся.
- Условия: https://www.cbr.ru/about/ — разрешено воспроизведение со ссылкой на первоисточник; одновременно есть оговорка о коммерческом использовании и уведомлении пресс-службы при некоторых формах включения ссылок в собственный ресурс. Это не безусловное разрешение нашего сценария.
- Технические рекомендации https://www.cbr.ru/development/ — минимизация запросов и промежуточное хранение; числовой лимит именно RSS не подтверждён.
- Попытка прочитать https://www.cbr.ru/robots.txt через инструмент исследования не удалась; вариант https://cbr.ru/robots.txt вернул 403. Содержимое и правила robots.txt не подтверждены. Обход ограничений не выполнялся.

**Решение: источник отключён.** Автоматическое получение для нашего использования не подтверждено. Универсальный адаптер проверяется только на локальных синтетических XML и fake HTTP/DNS; реальные публикации в Git не добавляются. Перед включением нужно проверить robots.txt и условия повторно, согласовать права использования, атрибуцию и частоту запросов. Публичность RSS не является разрешением на scraping страниц статей. Коллектор не загружает статьи или ресурсы из HTML.
