# Сценарий для жюри: 3–4 минуты, без платных запросов

1. Открыть http://localhost:8080, войти как demo-analyst со своим локальным
   паролем из .env. Выбрать SYNTH-SUBMISSION-001.
2. Показать профиль: отрасль, диапазон сотрудников, неизвестные единицы/год
   выручки. Название компании не выдумано, идентификатор технический.
3. Пульс -> Инсайты -> Проанализировать новость. Заголовок:
   «Учебная ставка и инвестиции в оборудование».

Текст для вставки:

> СИНТЕТИЧЕСКАЯ НОВОСТЬ ДЛЯ ДЕМОНСТРАЦИИ. Учебный регулятор сохранил ключевую
> ставку на уровне 14%. Производители оборудования оценивают возможное влияние
> на спрос и инвестиционные планы. Условия банковских договоров и наличие
> задолженности выбранной компании не указаны.

4. Указать, что сверху написано «Локальная проверка без LLM».
   Подтвердить право передачи текста и запустить анализ. В fake-режиме
   ничего не отправляется провайдеру.
5. Открыть инсайт: локальная заглушка, точный синтетический TXT, financial review.
   UNKNOWN/NEEDS_REVIEW — необходимость проверки, а не сертификат достоверности.
   Позиция Альфа-Банка не приписывается синтетическому TXT.
6. Лента показывает сохранённый результат. «Подобрать сохранённые новости» ->
   выбрать ту же -> анализ возвращает COMPLETED cache без нового draft.
7. Можно выбрать вторую компанию и ту же новость: её анализ независим,
   в ответе отражается другая отрасль. Это демонстрация контекста, не качества LLM.
8. Logout отзывает серверную сессию.

Если показывается сохранённый настоящий smoke из отдельного локального окружения:
не нажимать запуск снова, открыть готовую карточку.
Факты ранее выполненного теста: 1 SDK request, 1395 input / 1523 output,
из output 955 reasoning, total 2918; HTTP 201, COMPLETED.
Reviewer: 14 UNKNOWN, 7 NEEDS_REVIEW; финансовая корректность UNKNOWN.
Материалы и компания того теста были синтетическими.
Не выдавать его за production-анализ реальной компании или новые доказательства точности.

Никакого платного organizer включения для этого сценария не требуется.
